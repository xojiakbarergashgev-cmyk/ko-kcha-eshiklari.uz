🚀 Botni Telegramda ishga tushirish (3 oddiy qadam)

Barcha fayllar allaqachon tayyorlangan. Botni o'z tokeningiz bilan ishga tushirish uchun quyidagi ko'rsatmalarga rioya qiling:

1

Telegramda yangi bot ochish va Token olish

Telegramda @BotFather rasmiy botini oching va quyidagi buyruqlarni bering:

/newbot

Botingiz uchun nom (masalan: Ko'kcha Eshiklar) va username (masalan: kokcha_doors_bot) kiriting. BotFather sizga quyidagi ko'rinishdagi tokenni beradi:

7123456789:AAFoZ..._misol_token...
2

.env sozlama faylini to'ldirish

Loyiha papkasidagi .env.example faylidan nusxa olib, .env fayli yarating va tokeningizni yozing:

BOT_TOKEN=SIZNING_BOTFATHER_TOKENINGIZ
ADMIN_IDS=SIZNING_TELEGRAM_ID
SHOP_PHONE=+998 71 200 88 99
O'z Telegram ID raqamingizni bilish uchun Telegramda @userinfobot ga kiring.
3

Kutubxonalarni o'rnatish va botni yurgizish

Terminalda loyiha papkasiga o'tib quyidagi buyruqlarni bajaring:

# 1. Virtual muhit yaratish
python3 -m venv venv
source venv/bin/activate

# 2. Kutubxonalarni o'rnatish
pip install -r requirements.txt

# 3. Botni ishga tushirish
python3 bot.py
